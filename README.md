# 🚀 Beginner Level Frontend Projects

This repository contains a collection of **basic and beginner-friendly projects** built using **HTML, CSS, and JavaScript**. Each project focuses on fundamental web development concepts like DOM manipulation, user input handling, basic design, and interactivity — perfect for learners, students, and curious coders.

> 💻 All projects are 100% frontend-only — no backend, no frameworks, just clean web dev practice!

---

## 📦 Projects Included

### 🎓 University of Rajasthan - Website Clone
A simplified static clone of the official university website — focused on structure and layout using HTML & CSS.

### 🧮 Age Calculator
Enter your birthdate and get your exact age in years, months, and days. Uses date logic in JavaScript.

### 🎨 Canvas Drawing App
A basic canvas setup where users can draw using mouse input. Built using the `<canvas>` element and JS.

### ⏰ Analog Clock
A working analog clock that updates in real-time using JavaScript’s `Date()` object.

### 🌙 Dark Mode Toggle
A simple light/dark theme switcher for practicing DOM manipulation and CSS variables.

### 🕐 Digital Clock
Displays the current time in digital format (HH:MM:SS) — updates live.

### 🔐 Password Strength Checker
Checks and displays how strong your password is based on criteria like length, characters, and symbols.

### 🎲 Random Color Generator
Click to generate a new random color every time — also displays the color code.
